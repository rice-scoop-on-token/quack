# Quack animal assets

Quack 앱에서 쓰는 선생님 캐릭터 에셋입니다. 원본 작업 폴더의 `animations_v6` 결과를 앱용으로 줄인 버전이며, 앱은 이 폴더만 기준으로 사용합니다. 구버전 `assets/characters` 폴더는 참조하지 않습니다.

## 원본 위치

레포 밖, 에셋 담당이 보관합니다(팀 드라이브 예정). 이 폴더는 원본을 아래 "앱용으로 줄인 방법"대로 줄인 복사본이라, 시트를 고칠 때는 원본을 고친 뒤 같은 방법으로 다시 줄여 같은 경로에 파일만 바꿉니다.

## 포함 범위

- 동물: `cat`(고양이), `duck`(러버덕), `raccoon`(앱 표시 이름은 **너구리**)
- 성장 단계: `baby`(아기), `child`(어린이), `adult`(성체)
- 각 단계마다 기본 PNG 1장과 동작 시트 12장
- 총 117개 PNG: 기본 9장 + 동작 시트 108장

폴더 이름 `duck`은 앱의 동물 id `rubber_duck`에 해당합니다. 폴더 이름은 바꾸지 않고, 앱의 이미지 맵 파일 한 곳에서 연결합니다.

펭귄, 눈썹 버전, 액세서리 버전, 과거 애니메이션 버전은 MVP 범위에서 제외했습니다.

## 이미지 규격

| 종류 | 규격 | 설명 |
| --- | --- | --- |
| `base.png` | 512×512 RGBA | 정면 기본 에셋, 투명 배경 |
| `actions/*.png` | 1536×256, 256색(투명 포함) | 256×256 프레임 6개가 왼쪽에서 오른쪽 순서로 배치된 시트 |

모든 동작 시트는 프레임이 서로 침범하지 않도록 분리되어 있습니다. 프레임 인덱스는 `0...5`입니다.

동작 시트 위치를 발밑 가운데 기준으로 맞췄습니다(일부 프레임은 잘림 때문에 가능한 만큼만). 그래서 몇몇 시트는 그림이 칸 경계에서 1~3px까지 가깝습니다.

### 앱용으로 줄인 방법

앱 번들과 git 레포 크기 때문에 원본(약 32MB)을 약 5MB로 줄였습니다.

- `base.png`: 1254×1254 → 512×512. 픽셀 격자가 반듯한 픽셀 아트가 아니라 가장자리가 부드럽게 섞인 그림이라 Lanczos로 줄였습니다(nearest-neighbor로 줄이면 계단이 생깁니다).
- `actions/*.png`: 크기는 그대로 두고 색만 256색으로 줄였습니다(디더링 없음). 화면 표시 크기와 프레임 크기(256px)가 비슷해서 크기를 줄이지 않습니다.

## 경로 규칙

```text
animal/{animal}/{stage}/base.png
animal/{animal}/{stage}/actions/{action}.png
```

## 동작 이름

| 파일명 | 의미 |
| --- | --- |
| `idle` | 기본 대기 |
| `walk` | 걷기 |
| `run` | 달리기 |
| `read` | 읽기 |
| `think` | 생각 |
| `dejected` | 시무룩 |
| `angry` | 화남 |
| `happy_jump` | 신나게 점프 |
| `sleep` | 수면 |
| `surprised` | 놀람 |
| `tired` | 지침 |
| `study` | 공부 |

화면 상태별로 어떤 동작을 보여 줄지는 앱 코드 한 곳에서 정합니다. `manifest.json`의 `mvp.screenActions`는 에셋 담당의 처음 제안입니다.

## 성장 단계 임시 기준

앱의 임시값(`frontend/src/api/tempContract.ts`의 `STAGE_XP`)과 같습니다.

- `baby`: 0~99 XP
- `child`: 100~299 XP
- `adult`: 300 XP 이상

## 앱에서 쓸 때 지킬 것

- Metro의 `require()`는 동적 문자열을 지원하지 않습니다. 경로를 조합해 부르지 말고, 모든 경로를 적은 정적 이미지 맵만 씁니다.
- 동작 시트는 한 이미지 전체를 화면에 보여 주지 않습니다. 256×256 한 칸만 보이게 잘라서 왼쪽부터 차례로 넘기고, 마지막 칸 다음은 첫 칸으로 돌아갑니다.
- 기본 PNG는 `resizeMode="contain"`으로 비율을 유지합니다.
