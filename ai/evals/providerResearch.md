# LLM 제공자와 대상 연령 검토

- 조사·승인 기록일: 2026-11-02
- 범위: 미성년자를 포함하는 꽥 MVP에서 Google Cloud의 Gemini 생성형 AI와 OpenAI API를 사용할 수 있는지에 대한 1차 문서 조사
- 상태: 아래 방향은 AI 담당 사용자 승인 완료. 팀 전체 합의, 운영 조건 충족 및 특정 모델 선택은 아직 확인되지 않았다.
- 실제 API 호출, 계정·결제 설정 및 미성년자 대상 시험은 하지 않았다.

## 승인한 방향

1. 초기 대상은 만 14세 이상으로 검토한다. 미성년자 지원 방향은 유지하되 만 14세 미만 지원은 후속 검토로 둔다.
2. OpenAI API를 우선 후보로 둔다. 제공자 운영 적합성이나 특정 모델의 성능을 최종 확정한 것은 아니다.
3. 미성년자의 보호자 동의, 연령에 맞는 보호 조치와 개인정보 처리는 FE·BE 및 팀과 별도로 설계·검토한다. 이 결정을 했다는 이유로 미성년자에게 바로 공개 가능한 상태라고 보지 않는다.
4. Google의 표준 생성형 AI 서비스 약관에 있는 연령 제한 때문에 이번 미성년자 포함 방향에서는 Gemini 도입을 보류한다.

ChatGPT 사용자 구독과 OpenAI API 이용을 구분한다. 앱 연동 대상은 OpenAI API이며, 구독 보유만으로 API 설정·크레딧·이용 조건이 모두 충족됐다고 가정하지 않는다.

## 확인한 근거와 판단

| 검토 항목 | 공식 문서에서 확인한 내용 | 꽥에 대한 판단·제안 |
| --- | --- | --- |
| Gemini Developer API | 개발자 연령뿐 아니라 18세 미만을 대상으로 하거나 그들이 이용할 가능성이 있는 API 앱에도 제한을 둔다. [S1] | 미성년자를 대상으로 하는 이번 MVP의 후보로 채택하지 않는다. |
| Google Cloud 생성형 AI | 서비스별 약관 20(d)에도 18세 미만 대상 또는 이용 가능성이 있는 앱에 대한 제한이 있다. [S2] | AI Studio 대신 유료 Cloud 경로로 바꾸는 것만으로 연령 문제를 해결했다고 볼 수 없다. |
| OpenAI API의 미성년자 지원 | 미성년자를 서비스하는 개발자 지침이 있고, 서비스 계약은 보호자 동의 없는 미성년자 사용을 허용하지 않도록 규정한다. [S3, S4] | 연령·동의·보호 조치를 마련하는 조건으로 우선 검토할 수 있다. 무조건 사용 가능하다는 결론은 아니다. |
| 어린 아동의 개인정보 | OpenAI 지침은 만 13세 미만 또는 적용되는 디지털 동의 연령 미만 아동의 개인정보 처리 전에 ZDR 적용을 요구한다. ZDR은 사전 승인과 추가 요건이 있는 제도다. [S3, S5] | 어린 아동 지원을 초기 MVP에 함께 넣으면 별도 데이터 처리·승인 검토가 필요하다. |
| 한국의 아동 개인정보 | 만 14세 미만 아동의 개인정보 처리에 법에 따른 동의를 받아야 할 때는 법정대리인 동의와 그 확인이 필요하다. [S6] | 만 14세 이상부터 시작하고, 그 미만은 별도 후속 검토로 두는 근거다. 14세 이상이면 다른 동의·보호 의무도 없어지는 것은 아니다. |
| API 데이터의 학습 이용 | OpenAI API는 명시적인 공유 동의가 없으면 모델 학습·개선에 데이터를 사용하지 않는다. Google Cloud도 고객 허락·지시 없는 고객 데이터 학습·미세조정을 제한한다. [S2, S5] | 학습에 사용하지 않는다는 조건은 검토에 유리하지만, 연령 제한과 보관 문제를 해결하는 조건은 아니다. |
| OpenAI 데이터 보관 | 악용 방지 로그는 기본 최대 30일 보관될 수 있고 예외 및 기능별 저장이 있다. `store: false`는 ZDR 승인·적용 자체가 아니다. [S5] | 학습 자료·설명·음성에 개인정보가 섞일 수 있으므로 보관·삭제와 전송 범위를 별도로 설계해야 한다. |

위 표의 마지막 열은 공식 문서의 직접적인 사용 허가가 아니라, 확인한 조건을 바탕으로 한 프로젝트 판단이다. Google Cloud 전체를 미성년자 서비스에서 사용할 수 없다고 결론 낸 것은 아니며, 이번 비교는 Google이 제공하는 생성형 AI 서비스 경로를 대상으로 한다.

## 선택 이유와 대안

- OpenAI API 우선 검토 이유: 미성년자 지원 지침에 따라 조건을 검토할 수 있는 경로가 확인됐다. 이번 선택은 성능·가격 우위가 검증됐기 때문이 아니다.
- 만 14세 이상으로 초기 범위를 좁힌 이유: 미성년자도 지원하려는 의도를 유지하면서, 만 14세 미만 개인정보 처리와 어린 아동의 API 데이터 보관에 대한 추가 검토를 후속 작업으로 분리하기 위해서다.
- 보류한 대안: Google Gemini는 표준 연령 제한으로 이번 방향에서 보류한다. OpenAI의 조건을 팀이 감당하기 어렵다면 성인 대상 MVP 또는 다른 제공자를 다시 검토한다.
- 향후 확장: 만 14세 미만 지원은 보호자 동의·확인 방식, 적용되는 연령 기준, ZDR 적격성·승인 및 실제 전송 데이터 등을 확인한 뒤 재판단한다. 보호자 동의만 받으면 모든 조건이 해결된다고 보지 않는다.

## 아직 확인하거나 결정하지 않은 것

- 팀 전체의 대상 연령과 제공자 방향 승인
- 연령 확인·보호자 동의·안내 UI 및 운영 대응 방식
- 실제 입력 자료·설명·음성의 개인정보 범위와 외부 API 전송·보관·삭제 처리
- 적용 계약과 국내 운영 요건을 충족하는 구체적인 방법
- 사용할 LLM 모델과 한국어 대화·튜티 행동·JSON 출력의 실제 평가
- 모델별 요금, 지연 시간, 입력 한도, 계정에서의 접근 가능 여부
- STT 제공자와 실제 녹음 품질 검증. LLM 우선 후보 선택으로 STT까지 확정하지 않는다.
