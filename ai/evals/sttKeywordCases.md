# 이분 탐색 전사 용어 힌트 비교

[기존 Chrome 전사](sttPlan.md)에서 `이분 탐색` 힌트는 해당 용어를 바로잡았고, `O(log n)` 힌트가 있어도 ‘비로그 n’은 남았다. 같은 녹음에 힌트 조건만 바꿔, 발음 표기를 추가하면 수식을 더 잘 전사하는지와 말하지 않은 수식이 새로 들어가는지를 확인한다.

## 녹음 대본

제공된 M4A 두 파일을 사용했다. 사용자가 더 짧은 파일을 B로 지정했고, 재생 시간은 파일의 미디어 헤더에서 확인했다. 사용자가 녹음에 대응시킨 아래 대본을 비교 기준으로 썼다.

**A · 수식 포함 (`녹음 (2).m4a`, 10.625초)**

> 이분 탐색은 정렬된 배열에서 가운데 값과 목표 값을 비교해. 비교할 때마다 탐색 범위가 절반으로 줄어들어서 어... 시간 복잡도는 빅 오 로그 엔이야.

**B · 수식 생략 (`녹음 (3).m4a`, 7.339초)**

> 이분 탐색은 정렬된 배열에서 가운데 값과 목표 값을 비교해. 비교할 때마다 탐색 범위가 절반으로 줄어들어.

## 전사 조건

두 파일 각각에 아래 세 조건을 적용했다. 파일별로 같은 음원을 재사용했고 모델 `gpt-transcribe`, 언어 힌트 `ko`, MIME 타입 `audio/mp4`를 유지했다. 조건마다 한 번씩, 총 6회 전사했다. 자동 재시도는 0회다.

| 조건 | 용어 힌트 |
| --- | --- |
| 1. 없음 | 빈 목록 |
| 2. 표기 | `이분 탐색`, `O(log n)` |
| 3. 표기와 발음 | `이분 탐색`, `O(log n)`, `빅 오 로그 엔` |

조건 1과 2로 기존 용어 힌트의 효과를, 조건 2와 3으로 발음 표기를 추가한 효과를 본다.

## 판정과 기록

- **A:** `이분 탐색`과 ‘범위가 절반으로 줄어든다’는 의미가 유지되는지, `O(log n)` 또는 뜻이 같은 발음 표기가 남는지 확인한다. ‘비로그 n’처럼 수식의 뜻이 불명확하면 해당 항목을 오인식으로 기록한다.
- **B:** `이분 탐색`과 범위 축소는 유지되어야 한다. 말하지 않은 `O(log n)` 또는 같은 뜻의 표현이 들어가면 수식 추가로 기록한다. 힌트가 없는 조건에서도 같은 항목을 확인한다.
- 각 응답에 대본 ID, 조건, 실제 전사문, 핵심 용어와 범위 축소 보존 여부, 수식 복원·오인식·추가 여부, 요청 시간을 남긴다.
- 발음 표기 추가는 A에서 수식을 더 정확히 남기고 B에서는 수식을 추가하지 않았을 때 후속 평가 후보로 둔다. 한 화자와 파일 두 개의 관측이므로 반복 안정성이나 시연 환경에서의 성능은 이후 검증한다.

| 대본 | 조건 | 수식 표현 | 판정 | 요청 시간 |

| B | 표기 | 없음 | 수식 추가 0건 | 1.529초 |
| B | 표기와 발음 | 없음 | 수식 추가 0건 | 1.061초 |

A에서는 표기 힌트만으로도 수식의 의미가 보존됐다. 발음 힌트를 함께 넣은 응답은 대본의 발음 표기와 일치했다. B에서는 세 조건의 전사문이 같았고 수식이 추가되지 않았다. 이 관측에서는 표기 힌트와 발음 힌트 조건이 수식의 의미를 똑같이 보존했다. 두 조건 간 의미 정확도 차이와 PC 웹 WebM에서의 재현 여부는 추가 표본이 필요하다. 채점은 제공된 대본과 파일 배정을 기준으로 했으며, 음원을 별도로 청취해 대본과 대조하지 않았다.
