# 선형대수 평가 사례 초안

- 기록일: 2026-11-02
- 상태: 포크한 채팅에서 사용자와 검토한 사례 8개와 수정 원칙을 인계하기 위한 문서다. AI 담당 사용자 검토·기록 승인 범위이며 팀 전체 합의나 제품 구현 완료를 뜻하지 않는다.
- 문제와 발화는 평가를 위해 자체 작성했다. 실제 모델 호출·성능 평가 결과는 없다.
- 기존 `README.md`, `cases.json`, 프롬프트, `shared/`는 이번 기록 작업에서 수정하지 않는다. 이 문서의 표현은 평가용이며 API 필드·enum 확정이 아니다.

## 인계 시 먼저 읽을 것

기존 `cases.json`의 이분 탐색 8개는 한 주제 안의 응답 상황을 점검한다. 이 문서는 문제 풀이 비중을 높여 다른 분야에서도 기준이 적절한지 검토하기 위한 추가 사례다. 수학 8개 중 1·2·3·4·6·7·8번은 문제 풀이 또는 풀이 설명이며, 5번은 행 연산의 원리에 초점을 둔다. 사례의 목표가 서로 다르므로 공통 목표 하나로 덮어쓰지 않는다.

### 사용자와 검토한 수정 원칙

1. **단순 계산 실수는 짧게 짚고 넘어간다.** 개념과 접근이 타당하면 계산 실수 하나로 전체 이해를 부정하거나 재설명을 강요하지 않는다. 2번은 최초 초안의 '부족 판정 후 재질문'을 사용자가 수정한 최종 방향이다.
2. 답의 정오와 개념·풀이 이해를 분리해서 기록한다. '개념 이해 충분'을 정답 보증으로 쓰지 않는다. 결과·접근·오류 원인의 구분은 평가용 분석 관점이며 새 API 필드를 확정한 것이 아니다.
3. 학습자는 수준에 따라 중간 풀이를 생략할 수 있다. 근거가 불확실하면 핵심 연결을 한두 번 짧게 확인하고, 확인된 기술은 매 문제마다 다시 묻지 않는다. 한두 번이라는 숫자는 모든 능력을 확인했다는 자동 기준이 아니다.
4. 수준은 '선형대수를 잘함'처럼 통째로 단정하지 않는다. 현재 세션에서 실제로 확인한 개념·기술별 근거를 사용한다. AI의 해설은 학습자의 수행 근거가 아니다.
5. 새 개념이나 앞뒤 충돌이 나타나면 그 부분만 확인한다. 앞서 후진대입을 했다는 이유로 자유변수도 안다고 추정하지 않는다.
6. 같은 실수가 반복되면 원인을 확인할 수 있지만, 반복 자체로 개념 오류를 확정하지 않는다.
7. 대체 풀이의 허용 여부는 학습 목표에 따른다. 가우스 소거법 수행이 목표라면 역행렬 풀이만으로 해당 목표를 확인했다고 보지 않는다.

### 기존 기준과 조정이 필요한 지점

- 기존 출력 초안의 충분 응답은 오류 배열이 비어 있는 방향이므로, '개념 이해 충분 + 계산 오류 있음'의 표현·응답 조합은 후속 합의가 필요하다. 기존 초안에 임의로 끼워 맞추지 않는다.
- 확인 전 유보, 부분 이해, 기술별 확인 이력과 질문 생략을 실제 API·DB·보상에 어떻게 반영할지는 FE·BE와 미합의다.
- 이 문서로 장기 학습자 프로필 저장이나 세션 간 기억을 승인한 것은 아니다.
- 평가 실행 도구·출력 스키마·자동 채점·프롬프트 통합은 아직 없다. 이 문서는 프롬프트를 작성하기 전에 추가 사례를 정리한 기록이다.

## 공통 문제 P1

```text
x +  y +  z =  6
2x + 3y + z = 11
x +  y + 2z =  9
```

정답은 `(x, y, z) = (1, 2, 3)`이다. 다음 행 연산을 차례로 적용한다.

```text
[1 1 1 |  6]     R2 <- R2 - 2R1     [1 1  1 |  6]
[2 3 1 | 11]     R3 <- R3 - R1      [0 1 -1 | -1]
[1 1 2 |  9]                        [0 0  1 |  3]
```

행 연산은 행렬의 행 전체에 적용한다. 기준 풀이의 사실과 아래 가상 학습자의 오류 발화를 구분한다.

## 1. 답·풀이·근거가 모두 충분함

- ID: `linear-algebra-01-sufficient`
- 목표: 가우스 소거법으로 P1의 해를 구하고 행 연산의 정당성, 후진대입 및 유일해 판단을 설명한다.
- 이전 맥락: 없음.

**학습자 발화**

> 확대행렬에서 R2에서 R1의 두 배를 빼고, R3에서 R1을 뺐어. 그러면 두 번째 행은 [0, 1, -1 | -1], 세 번째 행은 [0, 0, 1 | 3]이 돼. 다른 행의 배수를 더하거나 빼는 건 반대 연산으로 되돌릴 수 있으니까 해집합이 유지돼. 마지막 행에서 z=3, 두 번째 행에서 y=2, 첫 번째 행에서 x=1이야. 모든 변수 열에 피벗이 있고 모순인 행이 없으니 자유변수 없이 해가 하나야. 원래 식에 대입해도 우변이 6, 11, 9로 맞아.

**기대 분석·행동**

- 충분. 답·접근·계산·이번 목표의 근거가 타당하다.
- 이번 설명으로 확인한 관계만 인정한다. 다른 행렬 문제까지 모두 풀 수 있다고 확대하지 않는다.
- 누락·오류 없음. 질문 0개.

**AI 예시**

> 아, 해집합이 유지되도록 아래 성분을 없앤 다음, 마지막 식부터 거꾸로 대입하는 거구나. 모순도 자유변수도 없어서 해가 하나라는 것까지 이해됐어.

## 2. 접근은 맞지만 단순 계산 실수로 답이 틀림

- ID: `linear-algebra-02-arithmetic-slip`
- 목표: 1번과 같다.
- 이전 맥락: 같은 종류의 반복 오류는 아직 관찰되지 않았다.

**학습자 발화**

> R2에서 R1의 두 배를 빼고, R3에서 R1을 뺐어. 이 연산은 되돌릴 수 있어서 해집합이 같아. 두 번째 행은 [0, 1, -1 | 1], 세 번째 행은 [0, 0, 1 | 3]이야. 그래서 z=3, y=4, x=-1이 돼. 모든 변수 열에 피벗이 있고 모순인 행도 없으니 유일한 해는 (-1, 4, 3)이야.

**기대 분석·행동**

- 답은 오답이지만 개념·접근은 이번 목표에서 충분하다. 이를 무조건적인 '충분한 정답'으로 집계하지 않는다.
- 오류는 두 번째 행의 상수항 `11 - 2*6 = -1`을 `1`로 계산한 부분이다.
- 잘못 얻은 두 번째 행을 기준으로 한 후진대입은 일관된다. 후진대입까지 별개의 개념 오류로 중복 기록하지 않는다.
- 계산 실수를 짧게 교정하고 종료한다. 질문 0개. 재풀이를 강제하지 않는다.
- 최초 초안의 '부족' 및 '왜 1이 되었는지 재질문'은 사용자 수정으로 대체됐다. 이 방향의 출력 계약 표현은 미정이다.

**AI 예시**

> 소거하고 거꾸로 대입하는 흐름은 이해됐어. 다만 두 번째 행의 상수항은 11-12=-1이야. 그 부분만 고치면 해는 (1, 2, 3)이 돼.

## 3. 풀이 생략, 이전에 확인한 근거 없음

- ID: `linear-algebra-03-skipped-unverified`
- 목표: P1을 가우스 소거법으로 풀고 풀이 원리를 설명한다.
- 이전 맥락: 첫 문제이며 학습자의 해당 기술을 아직 확인하지 않았다.

**학습자 발화**

> 가우스 소거법으로 풀면 z=3이고, 대입하면 y=2, x=1이야. 해는 하나야.

**기대 분석·행동**

- 답은 맞다. 소거 과정과 유일해 판단의 이해는 아직 확인되지 않았다.
- 생략만으로 지식 부족이나 오류를 확정하지 않는다. 확인 전 평가 상태를 어떻게 계약에 담을지는 미정이다.
- 전체 풀이를 다시 요구하지 않고 핵심 연결 하나를 질문한다.
- 후속 답변에서 확인한 내용만 인정한다. 유일해 기준에 답했다는 이유로 미제시 계산까지 모두 검증했다고 보지 않는다.

**AI 예시**

> 답은 따라왔어. 그런데 소거한 뒤 어떤 모양이 나왔길래 해가 하나라는 걸 알 수 있었어?

## 4. 같은 생략 풀이, 앞선 대화에서 기술 확인됨

- ID: `linear-algebra-04-skipped-verified`
- 목표: 가우스 소거법을 이용해 P1을 푼다.
- 이전 맥락: 현재 세션의 앞선 문제에서 학습자가 직접 유효한 행 연산과 후진대입을 수행했고, 짧은 확인에 아래처럼 답했다. 이 맥락은 실제 평가 입력에 포함해야 하며 메모만 붙여 놓고 모델이 알고 있다고 가정하지 않는다.

**앞선 학습자 발화**

> 행의 배수를 다른 행에 더하는 건 되돌릴 수 있어서 해집합이 유지돼. 모순인 행이 없고 모든 변수 열에 피벗이 있으면 자유변수가 없어서 해가 하나야.

**현재 학습자 발화**

> 가우스 소거법으로 풀면 z=3이고, 대입하면 y=2, x=1이야. 해는 하나야.

**기대 분석·행동**

- 충분. 현재 답은 맞고 생략한 기술에는 이전 수행 근거가 있으며 충돌이 없다.
- 같은 원리를 매번 다시 설명시키지 않는다. 질문 0개.
- 3번과 현재 발화가 같아도 이전 맥락과 이번 목표를 고려해야 한다.

**AI 예시**

> 응, 앞에서 했던 방식으로 소거하고 거꾸로 대입한 거구나. 이번 해도 (1, 2, 3)으로 맞아.

## 5. 답은 맞지만 행 연산의 정당성을 잘못 설명함

- ID: `linear-algebra-05-wrong-justification`
- 목표: P1 풀이에서 행 연산이 해집합을 보존하는 이유를 설명한다.

**학습자 발화**

> 소거해서 답은 (1, 2, 3)을 얻었어. 행 연산으로 해가 유지되는 건, 다른 행의 배수를 더하면 각 방정식의 계수랑 우변이 원래와 똑같이 남기 때문이야.

**기대 분석·행동**

- 부족: 개념 오류. 답은 맞지만 계수와 우변이 변하지 않는다는 근거는 틀렸다.
- 해당 행 대체 연산을 되돌릴 수 있어 동치인 연립방정식을 얻는다는 점과 혼동했다.
- 정답만으로 이해를 인정하지 않는다. 충돌하는 지점 하나를 질문하며 원리를 먼저 해설하지 않는다.

**AI 예시**

> 그런데 두 번째 행에서 첫 번째 행의 두 배를 빼면 계수와 우변이 바뀌잖아. 식이 달라져도 같은 해를 갖는 이유는 뭐야?

## 6. 계산 오류가 반복돼 규칙을 확인해야 함

- ID: `linear-algebra-06-repeated-subtraction`
- 목표: 소거 과정에서 음수와 뺄셈을 올바르게 처리한다.
- 이전 맥락: 앞선 문제에서 학습자가 `5-8=3`으로 계산했고, AI가 `-3`이라고 짧게 교정했다. P1에서도 `11-12=1`이라고 계산한 상태다.

**학습자 발화**

> 이번에도 큰 수에서 작은 수를 빼서 1이라고 썼어.

**기대 분석·행동**

- 같은 오류의 반복과 현재 발화는 뺄셈을 항상 양수 차이로 처리하는 규칙을 사용했을 가능성을 보여준다.
- 반복만으로 개념 오류를 확정하지 않는다. 단순 실수인지 규칙의 오해인지 확인한다.
- 가우스 소거법 전체를 다시 묻지 않고 해당 계산 규칙만 질문한다.

**AI 예시**

> 아, 두 수의 차이를 양수로 적은 거구나. 그런데 여기서는 11-12인데, 뺄셈 순서가 바뀌어도 결과가 같다고 생각한 거야?

## 7. 계산은 맞지만 새 개념인 자유변수를 오해함

- ID: `linear-algebra-07-free-variable`
- 목표: 자유변수가 있는 연립방정식의 해를 표현한다.
- 이전 맥락: 행 연산과 후진대입은 확인했지만 자유변수는 아직 확인하지 않았다.
- 이 사례의 별도 문제 P2:

```text
x +  y +  z = 3
2x + 2y + 2z = 6
x -  y +  z = 1
```

기준 해집합은 `(x, y, z) = (2-t, 1, t)`, `t`는 임의의 실수다.

**학습자 발화**

> 소거하면 y=1, x+z=2가 나와. z에는 피벗이 없으니까 z=0으로 정하면 돼. 그래서 유일한 해는 (2, 1, 0)이야.

**기대 분석·행동**

- 부족: 자유변수와 유일해의 관계 오류.
- 소거 결과와 제시한 해 하나는 맞다. 자유변수를 0으로 택해 해 하나를 찾는 것과 반드시 0이어야 한다는 주장·유일해 결론을 구분한다.
- 앞서 확인한 행 연산을 반복 질문하지 않는다. 다른 해 하나와의 충돌을 보여 주며 새 개념만 확인한다.

**AI 예시**

> (2, 1, 0)이 식을 만족하는 건 이해됐어. 그런데 z=1로 두고 x=1로 잡아도 식이 맞는 것 같은데, 해가 하나라는 설명과는 어떻게 연결돼?

후속 답변에서 매개변수로 해를 표현하는지 확인한다. 제시한 다른 해는 반례이며 일반해를 먼저 전부 알려준 것은 아니다.

## 8. 다른 유효한 풀이를 사용함

- ID: `linear-algebra-08-alternative-method`
- 목표: P1의 해를 구하고 선택한 풀이가 성립하는 이유를 설명한다. 풀이법은 지정하지 않는다.

**학습자 발화**

> A x = b로 놓고 역행렬로 풀었어. A의 행은 [1,1,1], [2,3,1], [1,1,2]이고, b는 [6,11,9]야. det A=1이라 역행렬이 존재해. 역행렬의 행은 [5,-1,-2], [-3,1,1], [-1,0,1]이야. 양변 왼쪽에 역행렬을 곱하면 x=A의 역행렬 곱하기 b가 되고, 계산하면 (1,2,3)을 얻어. 역행렬이 있으니 해도 하나야.

**기대 분석·행동**

- 충분. 역행렬·계산 결과·적용 근거가 타당하다. 질문 0개.
- 소거법을 사용하지 않았다는 이유로 다시 풀게 하지 않는다.
